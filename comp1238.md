## Week 1 - History
- One writing system can be used by many languages
- Cuneiform was an early writing system

## Week 2 - Bits and Bytes
- Binary consists of 0s and 1s representing off and on states
- A byte is made up of 8 bits

## Week 3 - Hardware
- ATX and Micro-ATX define motherboard form factors
- ATX12V standards specify power supply standards for system stability

## Week 4 - Memory
- DDR5 DIMMs feature lower operating voltages and on-die ECC
- Dual-channel memory configurations improve bandwidth performance

## Week 5 - Web Publishing
- GitHub Pages automatically renders Markdown files into web pages
- Jekyll themes customize the visual appearance of the published site
